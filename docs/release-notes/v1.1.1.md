### 新功能
- **设置面板** 改为侧栏分页：隐私屏保 / 快捷键 / 系统 / 关于
- **多显示器** 遮蔽范围可切换「全部显示器 / 仅主屏」，遮罩开启时立即生效
- **开机自启** 系统页可开关（登录后自动运行，不会自动开启遮罩）
- **数据管理** 系统页可查看数据目录与日志路径、打开数据文件夹；安装版日志移至 `%APPDATA%\Veil`
- **快捷键** 录制时按键被其他程序抢走（如微信截图键）会提示换一个，不会出现两边同时响应

### 界面优化
- 快捷键的禁用 / 启用改为开关式按钮，说明文字按条目分行
- 提示条移到窗口顶部，不再遮挡内容
- 关于页全新设计，含 GitHub 入口
- 移除 F13~F24 热键支持（普通键盘没有这些实体键）

### 问题修复
- **界面** 修复 v1.1.0 安装包 / 压缩包内设置界面为旧版的问题（开关按钮、说明排版等已全部恢复）

### 已知问题
- **UU 远程** 首次开启遮罩后，远控端鼠标光标消失约 10 秒再自动恢复，之后正常
- **快捷键** 用键盘钩子实现的快捷键（如微信截图键）检测不到占用，同一组合会双方同时响应
- **遮罩** UAC 管理员确认弹窗和锁屏界面盖不住，两个版本都一样
- **开机自启** 注册表自启路径的 UIAccess 权限仍在验证中（如重启后候选窗盖不住请反馈）

### 下载说明
- **安装版** `…-setup.exe`：需管理员确认一次，固定安装到 `C:\Program Files\Veil`
- **便携版** `…-portable.zip`：解压即用，免安装免管理员
- 本项目没有购买代码签名证书，安装包运行时 Windows 会提示"未知发布者"
- 安装时会在你的电脑上生成一张自签名证书给 `Veil.exe` 签名，加入本机受信任的根证书，并立即删除证书私钥；卸载时证书一并移除
